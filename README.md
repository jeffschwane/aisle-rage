# Aisle Rage: City Point

A 32-bit-style browser game set in the Downtown Brooklyn (City Point) Trader Joe's. Grab your list, dodge shoppers, catch the end of the line.

**Play:** https://jeffschwane.github.io/aisle-rage/

- Global Hall of Fame stored in Supabase (`scores` table; anyone can read and add, nobody can edit or delete).
- Challenge links: `https://jeffschwane.github.io/aisle-rage/#beat-<name>-<score>`
- `card.png` is the link-preview image.
