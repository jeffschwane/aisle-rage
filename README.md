# Aisle Rage: City Point

Launch page for **Aisle Rage**, a 32-bit-style game set in the Downtown Brooklyn (City Point) Trader Joe's.

This page exists so shared links show the Aisle Rage title card in text-message and social previews. It forwards straight to the game, which runs on Claude:
https://claude.ai/artifact/T5KHvWWfQSYVHv8vEzus2M

Challenge links keep the score to beat, e.g. `https://jeffschwane.github.io/aisle-rage/#beat-jeff-7015`.
